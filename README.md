# 📚 Word Bot — телеграм-бот для запоминания английских слов

Кидаешь боту английские слова в течение дня — он находит перевод, определение
и пример, сохраняет их и **сам проверяет тебя в случайное время** по методу
интервального повторения (spaced repetition). Сделано как MVP и подробно
прокомментировано, чтобы было понятно, как всё работает.

---

## Что умеет

- Присылаешь английское слово → бот даёт **слово, транскрипцию, перевод на
  русский, короткое определение и пример**.
- Под карточкой кнопки: **✅ Запомнил**, **🔁 Повторить позже**, **❌ Удалить**,
  **🔤 Мн. число** (покажет множественное число).
- В **случайное время** сам присылает слово и просит перевод — и наоборот
  (русское слово → пишешь английское). Режимы чередуются.
- Проверяет ответ **без учёта регистра, лишних пробелов и с допуском на мелкие
  опечатки**.
- **Интервальное повторение:** верный ответ → уровень выше и следующий показ
  позже (1ч → 1д → 3д → 7д → 14д). Неверный → уровень сбрасывается, слово
  вернётся скоро.
- Команды: `/list`, `/stats`, `/quiz`, `/delete слово`.
- Данные в **SQLite** (один файл), настроено на одного пользователя, но база
  готова к нескольким.

## Как устроен проект (файлы)

| Файл | За что отвечает |

| `bot.py` | Главный файл: команды, кнопки, планировщик проверок |

## Установка и запуск (шаг за шагом)

### 1. Получи токен бота
Напиши в Telegram боту **@BotFather** → команда `/newbot` → придумай имя →
он даст тебе **токен** (длинная строка вида `123456:ABC-...`).

### 2. Узнай свой user_id
Напиши боту **@userinfobot** — он пришлёт твой числовой `id`.

### 3. Установи зависимости
```bash
# создаём отдельное окружение (чтобы не мусорить в системе)
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate

pip install -r requirements.txt
```

### 4. Создай файл настроек `.env`
```bash
cp .env.example .env
```
Открой `.env` и впиши:
```
BOT_TOKEN=сюда_токен_от_BotFather
OWNER_USER_ID=сюда_твой_id
```
(`DEEPL_API_KEY` можно оставить пустым — тогда работает бесплатный Google
Translate. `CHECK_INTERVAL_MINUTES` — как часто бот проверяет базу, по
умолчанию 5 минут.)

### 5. Запусти бота
```bash
python bot.py
```
Теперь открой своего бота в Telegram, нажми **/start** и пришли первое
английское слово 🎉

> Бот работает, пока запущен `python bot.py`. Закроешь терминал — бот
> остановится (слова в базе сохранятся). Для постоянной работы его нужно
> держать запущенным на сервере — это уже следующий шаг после MVP.

## Как работает интервальное повторение

У каждого слова есть **уровень** от 0 до 5:

| Уровень | Следующий показ через |
|---------|-----------------------|
| 0 | 1 час |
| 1 | 1 день |
| 2 | 3 дня |
| 3 | 7 дней |
| 4 | 14 дней |
| 5 | **выучено** (больше не спрашивает) |

- Ответил **верно** → уровень +1 (показ реже).
- Ответил **неверно** → уровень 0 (показ скоро, через ~10 минут).

Так трудные слова возвращаются часто, а знакомые почти не отвлекают.

## Частые вопросы

**Бот присылает «TooManyRequests» или пустой перевод?**
Это лимит бесплатного Google Translate. Бот сам переключится на запасной
переводчик (MyMemory). Если нужно стабильнее — заведи бесплатный ключ DeepL и
впиши в `.env` в `DEEPL_API_KEY`.

**Где хранятся мои слова?**
В файле `words.db` рядом с ботом. Он в `.gitignore` и не попадёт в git.

**Как удалить слово?**
Кнопкой ❌ под карточкой или командой `/delete слово`.
